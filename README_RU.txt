SONIC.EXE — NIGHTMARE
=====================

Это исходный проект игры на Godot 4.x (3D, GL Compatibility).
Внутри — пять глав, тёмная атмосфера, фонарь, сбор осколков,
преследователь с красными глазами, сенсорные кнопки и управление клавиатурой.

ВАЖНО:
- Это ранняя играбельная основа, а не законченная коммерческая игра.
- В проекте используются процедурные примитивы вместо готовых моделей/музыки.
- Для сборки APK нужен Godot 4.x с Android export templates и Android SDK/JDK.
- Открой project.godot в Godot, проверь запуск, затем Project -> Export -> Android.
- На Android можно открыть проект в Godot Editor for Android, если версия поддерживает экспорт.
- Для экспорта APK настрой Android SDK/JDK и шаблоны экспорта в Editor Settings.

Управление:
WASD — движение; мышь / свайп справа — обзор; Shift — бег.
На экране есть сенсорные кнопки. Нажми «ВЗЯТЬ» у выхода после сбора осколков.

План глав:
I. Зелёный холм
II. Забытая станция
III. Лес шёпотов
IV. Красный коридор
V. Последний изумруд

Проект фанатский и неофициальный. Sonic и связанные персонажи принадлежат
их правообладателям; для публичного распространения используйте только
разрешённые/собственные материалы.
